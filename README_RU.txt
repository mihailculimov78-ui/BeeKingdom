BEEKINGDOM 0.2.0 — ОБНОВЛЁННЫЙ ИСХОДНЫЙ ПРОЕКТ
Minecraft Java / Paper 26.3 / Java 25

ЧТО ИЗМЕНЕНО
1. Исправлен слот конской брони: обычные клики в инвентаре игрока разрешены, shift-клик и перетаскивание в меню блокируются. Броню можно надеть и снять через слот экипировки.
2. Добавлена кнопка «Отпустить пчелу». Отпущенная пчела становится обычной, а запись удаляется из меню. Профили пчёл в выгруженных чанках сохраняются; при загрузке известного чанка удаляются записи, для которых сущность уже не существует.
3. Для приручённых пчёл регулярно сбрасывается флаг ужаливания, чтобы предотвратить их последующую смерть.
4. В режиме следования отключается обычный AI пчелы, включая конкурирующий поиск цветов; движение к владельцу выполняется плагином.
5. Приручение имеет шанс 35%. Значение настраивается в config.yml параметром taming-chance (0.35 = 35%).
6. Обновлено меню: фон, информационная панель, статусы, понятные подписи и кнопка освобождения.

СБОРКА
1. Загрузи всё содержимое папки BeeKingdom в корень GitHub-репозитория.
2. Открой Actions → Build BeeKingdom → Run workflow.
3. Дождись зелёной галочки и скачай артефакт BeeKingdom-JAR.
4. Внутри будет BeeKingdom-0.2.0.jar.

УСТАНОВКА
1. Останови сервер и сделай резервную копию.
2. Удали старый BeeKingdom-*.jar из папки plugins.
3. Загрузи новый BeeKingdom-0.2.0.jar в plugins.
4. Запусти сервер и проверь консоль.

ИСПОЛЬЗОВАНИЕ
- Мак в основной руке + ПКМ по дикой пчеле — попытка приручения.
- Ошейник: 8 поводков по краям верстака, центр пустой.
- ПКМ ошейником по воздуху или команда /beekdom открывает меню.
- В меню пчелы слот экипировки принимает конскую броню с курсора.
- Кнопка «Отпустить пчелу» удаляет связь с владельцем.
- Цель выбирается вводом ника онлайн-игрока в чат.

ВАЖНО
Это исходный проект, а не заранее собранный JAR. Совместимость API и отображение брони нужно проверить на твоей сборке Paper 26.3. Если GitHub Actions покажет ошибку, пришли текст ошибки — поправим.
