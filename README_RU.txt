BEEKINGDOM 0.1.0 — ПЕРВАЯ СБОРКА ПРОЕКТА
Цель: Minecraft Java 26.3 / Paper 26.3 / Java 25

ВАЖНО
В этом архиве находится исходный Maven-проект и автоматическая сборка через GitHub Actions.
Готовый JAR не приложен: среда, в которой был собран архив, имеет только Java 21 и не имеет Maven,
а Paper 26.3 требует Java 25 для корректной компиляции. Я не подменяю это непроверенным JAR.

ФУНКЦИИ ПЕРВОЙ ВЕРСИИ
- Приручение дикой пчелы маком (ПКМ).
- Привязка пчелы к UUID владельца.
- Рецепт ошейника: 8 поводков по краям, центр пустой.
- ПКМ ошейником открывает меню армии.
- Индивидуальное меню каждой прирученной пчелы.
- Режимы: следовать, свободный полёт, атака выбранного онлайн-игрока,
  мирный режим, агрессивный режим (атакует живых существ поблизости, кроме владельца и его же приручённых пчёл).
- Общая установка режима для всей армии.
- Сохранение владельца, режима, цели и брони в config.yml и PDC сущности.
- Слот для конской брони; предметный display прикрепляется к пчеле как пассажир.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ
- Для меню доступны пчёлы, профили которых сохранены; действия с пчелой требуют,
  чтобы её чанк был загружен. При выгрузке чанка профиль остаётся сохранённым.
- Визуальная броня — предметный display-пассажир. Положение/масштаб нужно проверить
  на сервере и при необходимости подстроить.
- В атакующем режиме пчёлы используют стандартный AI цели Minecraft; это не отдельная
  система навигации/боевого ИИ.
- Агрессивный режим выбирает живые существа рядом с пчелой; владелец и пчёлы того же владельца исключены.
- Для выбора цели нажми кнопку в меню и напиши ник в чат.

СБОРКА ЧЕРЕЗ GITHUB ACTIONS (НЕ НУЖЕН MAVEN НА ТВОЁМ ПК)
1. Создай пустой репозиторий GitHub с названием BeeKingdom.
2. Распакуй ZIP и загрузи ВСЁ содержимое папки BeeKingdom в корень репозитория.
   Важно: папка .github тоже должна попасть в репозиторий.
3. Открой вкладку Actions.
4. Выбери Build BeeKingdom и нажми Run workflow.
5. Дождись зелёной галочки.
6. Внизу страницы запуска скачай артефакт BeeKingdom-JAR.
7. Внутри архива будет BeeKingdom-0.1.0.jar.

УСТАНОВКА НА СЕРВЕР
1. Сделай резервную копию сервера.
2. Останови сервер полностью.
3. В файловом менеджере открой plugins.
4. Загрузи BeeKingdom-0.1.0.jar.
5. Запусти сервер.
6. В консоли проверь, что есть строка "BeeKingdom включён".

ИСПОЛЬЗОВАНИЕ
- Дикая пчела + мак в основной руке + ПКМ = приручить.
- Крафт ошейника: LLL / L_L / LLL, где L — поводок.
- Возьми ошейник в основную руку и нажми ПКМ по воздуху.
- /beekdom открывает меню без ошейника.
- В главном меню клик по пчеле открывает её индивидуальные настройки.
- В меню атаки введи ник онлайн-игрока в чат.
- Для брони положи конскую броню на курсор и нажми слот экипировки.
  Повторный клик по слоту без предмета снимает броню.

ПРАВА
beekdom.use — доступ к команде /beekdom (по умолчанию true).

ПРИМЕЧАНИЕ ПО СОВМЕСТИМОСТИ
Maven использует Paper API 26.3.build.242-stable и Java release 25.
Если у твоего Paper 26.3 другая сборка, совместимость API следует проверить по логу запуска.
